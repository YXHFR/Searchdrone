# Code of conduct

Searchdrone exists to help find people who are lost. We want working on it to feel safe and welcoming for everyone.

## Expected behaviour

- Be kind and patient. Assume good intent.
- Give and accept constructive criticism of code and ideas, never of people.
- Respect differing experience, opinions and backgrounds.
- Protect privacy: never share someone else's personal data, location or images.

## Not acceptable

- Harassment, insults, discriminatory jokes or personal attacks.
- Sexualised language or imagery.
- Publishing others' private information without explicit permission.
- Using the project to surveil, track or identify people without their consent.

## Scope

This applies in all project spaces: issues, pull requests, discussions and any other place where you represent the project.

## Enforcement

Report problems privately to the maintainer through GitHub (the repository owner). Reports are handled confidentially. The maintainer may remove content, or temporarily or permanently ban anyone who breaks these rules.
