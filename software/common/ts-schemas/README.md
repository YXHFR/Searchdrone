# @searchdrone/schemas

TypeScript types generated from the Python schemas in `sd_schemas`
(`software/common/schemas/`). Never edit `src/generated/` by hand: change the Python
models and run `just gen` from the repository root. `just gen-check` fails when the
generated files are out of date.

Part of the [Searchdrone](../../../README.md) monorepo. Licensed under Apache-2.0.
