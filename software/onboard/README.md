# sd-onboard (`sd_onboard`)

The onboard process `sd-onboard`: runs skills as state machines and talks MAVLink to the flight controller. Simulated on a PC in v0.1.

Part of the [Searchdrone](../../README.md) monorepo. Licensed under Apache-2.0.

Run its checks from the repository root: `just test` (all checks: `just check`).
